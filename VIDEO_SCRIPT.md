## Tips for recording

- Use **screen recording** on the phone (iOS: Control Center → record button. Android: pull-down → screen record).
- Or record on desktop with **OBS** at 1080p, browser zoomed to 90% so the layout stays mobile-shaped.
- Mute notifications first.
- Record in incognito mode so your previous session doesn't show.
- If recording on desktop, set browser viewport to 390 × 844 (iPhone 14 size) using DevTools device toolbar.

## If you want an AI-generated video instead

Paste this whole script into:
- **Synthesia** (https://www.synthesia.io) → adds a stock presenter reading the voiceover
- **HeyGen** (https://www.heygen.com) → similar
- **Pictory** (https://pictory.ai) → turns scripts into stock-footage videos
- **Veed** (https://www.veed.io) — also has script-to-video

For each scene, you can attach the matching screenshot from `images/` folder so the AI shows the right shot at the right moment.
